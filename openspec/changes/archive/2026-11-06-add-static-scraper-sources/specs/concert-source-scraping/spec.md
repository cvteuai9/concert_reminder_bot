## ADDED Requirements

### Requirement: 從年代售票抓取活動列表
System SHALL 從年代售票(Ticket.com.tw)的首頁活動列表抓取目前上架的活動,並回傳每個活動的標題、詳細頁連結,以及可取得的日期資訊。

#### Scenario: 成功抓取年代售票活動列表
- **WHEN** 系統對年代售票首頁發出請求且回應成功
- **THEN** 系統回傳一個活動清單,每個活動至少包含標題與可供識別的唯一 ID/連結

### Requirement: 從 udn售票網抓取活動列表
System SHALL 從 udn售票網的首頁活動列表抓取目前上架的活動,並回傳每個活動的標題、詳細頁連結,以及可取得的日期與場地資訊。

#### Scenario: 成功抓取 udn售票網活動列表
- **WHEN** 系統對 udn售票網首頁發出請求且回應成功
- **THEN** 系統回傳一個活動清單,每個活動至少包含標題與可供識別的唯一 ID/連結
